КРАСИВЫЕ АДРЕСА ДЛЯ GITHUB PAGES

1. Распакуйте архив.
2. Загрузите содержимое папки portfolio_pretty_urls в КОРЕНЬ репозитория GitHub (не саму папку).
3. При загрузке разрешите заменить существующие файлы.
4. НЕ УДАЛЯЙТЕ assets/, js/ (кроме обновления js/main.js), styles.css, star.glb и другие ресурсы.
5. В GitHub Pages должна использоваться публикация из ветки, без переопределяющей сборки.
6. Проверьте /about/, /projects/, /projects/multiself/ и кнопку Retour.

Старые HTML остаются на месте с клиентскими переадресациями. Это НЕ серверные HTTP 301 редиректы.
Ссылки используют абсолютные пути от корня домена mbandurian.com (CNAME).
